## 二、整体风格设定

### 设计参考
- Apple 官网产品页（大面积留白、超大标题、滚动叙事）
- Tesla 官网（深色背景、科技感、极简）
- Nothing 品牌（克制的高级感）

### 配色方案
| 用途 | 色值 |
|------|------|
| 背景主色 | `#000000`（纯黑） |
| 主题绿 | `#0F2E1C`（深墨绿） |
| 点缀金 | `#C9A86A`（香槟金） |
| 文字主色 | `#FFFFFF`（白） |
| 文字辅助 | `rgba(255,255,255,0.7)`（半透白） |
| 毛玻璃卡片 | `rgba(255,255,255,0.05)` + `backdrop-filter: blur(20px)` |

### 设计原则
- **一屏一个核心卖点**：每屏只说一件事
- **大量留白**：文字少而精，给画面呼吸感
- **超大标题**：字号 36-48px，视觉冲击力强
- **滚动叙事**：用户下滑时内容依次淡入
- **深色背景 + 金色点缀**：营造高端感
- **毛玻璃卡片**：科技感与质感并存

### 明确禁止的风格
- ❌ 淘宝详情页风格（堆砌、花哨）
- ❌ 工业控制后台风格（蓝灰、表格化）
- ❌ 传统企业官网风格（蓝色、保守）
- ❌ 蓝色科技公司模板风（俗套）

## 四、动画技术规格

### 动画库
- **GSAP**（GreenSock Animation Platform）
- **ScrollTrigger** 插件（滚动驱动动画）

### 各屏动画清单

| 屏次 | 动画类型 | 说明 |
|------|---------|------|
| Hero | 背景缩放 + 淡入 | CSS `transform: scale(1.05)` 缓慢进行；标题 opacity 0→1 |
| 痛点 | Scroll Fade In | scrollTrigger 触发，内容逐条淡入 (stagger: 0.3s) |
| 智能灌溉 | 卡片浮动 | translateY 微幅上下浮动 (y: -10, yoyo, repeat: -1) |
| 地埋美学 | Parallax | 背景图 translateY 速度慢于滚动速度 |
| 水路保护 | 左右滑入 | 左侧卡片 from left，右侧卡片 from right |
| 五档模式 | 圆形旋转 | 圆形菜单 rotate 360°，各图标依次 scale 弹出 |
| OTA | 粒子连接 | canvas 绘制粒子连线 + 数据流动光效 |
| 情感升华 | 逐句淡入 | 每句 0.8s 间隔，最后一句放大停留 |
| 报价页 | 数字滚动 | 总价从 0 快速滚动到 8350 |

### 性能要求
- 移动端 60fps 流畅运行
- 图片懒加载（进入视口前 200px 开始加载）
- 微信内置浏览器兼容（-webkit- 前缀）

## 八、免责与施工约定（可放在报价页底部折叠区域）

1. **既有管网**：本工程最大化利用业主既有地下管线，施工前进行常规压力与通水诊断。若原有暗管存在地下不可见暗漏或断裂，需由业主另行修复或委托本团队进行地上明管改造（费用另计）。

2. **水电接入**：业主需将 220V 电源及市政自来水总阀接口引至控制箱及电磁阀井周边 3 米范围内。

3. **水压说明**：喷洒效果基于标准市政动压（≥0.3 MPa）。若现场动压不足，需选配智能增压泵总成。
