# 网页优化方向与素材清单

## 当前最值得继续优化的方向

1. 主视觉统一性
   - 现在页面结构和动效已经成型，最缺的是每一屏高质量主图统一风格。
   - 建议统一为“暖金生活感 + 深绿科技感 + 黑金高端信息层”。

2. 信息层更像提案册
   - 可以继续减少单屏文字量，把长句拆成 2 到 3 组短句。
   - 每屏保留一个主标题、一个副论点、一个证据模块。

3. 动画更有节奏
   - Hero：慢速背景呼吸、按钮浮入、下滑提示。
   - 自动托管：湿度圆环 + 趋势线动态变化。
   - 雨鸟喷头：出土、展开、水雾轻微摆扫。
   - OTA：云端脉冲 + 粒子流。
   - 报价页：逐行浮现、总价滚动、金色扫光。

4. 更真实的产品感
   - 如果后续补齐 `sprinkler-asset.png`，可以替换当前程序化喷头前景。
   - 如果补齐 `rainbird.png` 和 `auto-irrigation.png`，第 3/4 屏会明显更像成片。

## 已准备好的生成脚本

- 单张生成：`generate_image_proxy.py`
- 批量生成：`generate_image_proxy_batch.py`
- 一键生成并复制到网页目录：`run_generate_assets.ps1`

## 本地一键生成命令

```powershell
$env:QWEAPI_KEY="你的代理key"
powershell -ExecutionPolicy Bypass -File .\run_generate_assets.ps1
```

生成完成后，图片会同时出现在：

- `output/imagegen/`
- `images/`

网页会自动读取 `images/` 目录里的文件。
