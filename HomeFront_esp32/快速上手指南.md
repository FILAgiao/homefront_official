# HomeFront 智能灌溉控制器 — 快速上手指南

---

## 一、烧录固件

**前置条件**：电脑已安装 VS Code + PlatformIO 插件。

1. **断开 RS485 模块**（GPIO1/3 和下载串口共用，不拔会烧录失败）
2. USB 线连接 ESP32 到电脑
3. 在 VS Code 中打开 `HomeFront_esp32` 文件夹
4. 点击底部状态栏的 `✓` 编译, 或终端执行:
   ```
   pio run
   ```
5. 编译通过后, 点击 `→` 上传, 或终端执行:
   ```
   pio run --target upload
   ```
6. 烧录完成后**重新插上 RS485 模块**

---

## 二、首次配置（WiFi 配网）

设备首次开机时, NVS 里没有 WiFi 信息, 会自动进入 **AP 配置模式**:

1. 上电后 OLED 不显示内容属正常（配置页通过网页操作）
2. 用手机或电脑搜索 WiFi, 连接热点 **`Homefront-Setup`**（无密码）
3. 浏览器打开 **`http://192.168.4.1`**, 看到配置网页
4. 填写以下必填项:
   - **SSID**: 你家的 WiFi 名称
   - **Password**: WiFi 密码
   - **Device ID**: 设备唯一标识（tlink.io 平台注册的设备 ID）
   - 阀门数量、水泵数量、浇水时长等按实际情况填写
5. 点击 **Save & Restart**, 设备自动重启并连接 WiFi

> 如果配置后需要修改参数, 可以通过 OLED 菜单的「参数设置」页面或重新进 AP 模式（菜单里选"恢复出厂"或清空 NVS）。

## 三、OLED 菜单操作

设备启动后, OLED 屏幕显示中文菜单, 通过旋钮和按键操作:

| 操作 | 功能 |
|------|------|
| 旋转 EC11 编码器 | 上下移动光标 |
| 按下编码器 | 确认 / 进入子菜单 |
| KEY1 | 返回上一级 |
| KEY2 | 快捷控制（快速开关阀门/水泵） |
| KEY3 | 紧急停止（立即关闭所有阀门和水泵） |

### 菜单页面:

| 页面 | 功能 |
|------|------|
| 状态信息 | 查看土壤湿度、阈值、当前模式、时间 |
| 阀门控制 | 手动开关每个阀门和水泵 |
| 模式选择 | 开关定时自动/湿度自动, 触发手动/洗车/菜地浇水 |
| 参数设置 | 修改所有 15 个参数（时长、时间、数量等） |
| 系统管理 | 保存配置、重连 WiFi、关于、重启、恢复出厂 |

### 参数编辑:

进入参数设置 → 选中某项 → 按下编码器进入编辑 → 旋转调整数值 → 按下确认（自动保存）

## 四、功能测试

### 4.1 继电器输出测试

进入 **阀门控制** 页面, 手动开关每个阀门和水泵, 用万用表测量对应继电器是否吸合:

| 继电器 | 595 通道 | 对应功能 |
|--------|----------|----------|
| RLY1 | bit 0 | 电磁阀 1 |
| RLY2 | bit 1 | 电磁阀 2 |
| RLY3 | bit 2 | 电磁阀 3 |
| RLY4-6 | bit 3-5 | 预留 |
| RLY7 | bit 6 | 水泵 |
| RLY8 | bit 7 | 备用水泵 |

### 4.2 土壤湿度传感器测试

1. 确保 RS485 传感器已连接
2. 进入 **状态信息** 页面查看 `soil_moisture` 读数
3. 用手握住传感器探头, 读数应上升; 放开后应下降
4. 串口监视器（`pio device monitor`）也能看到 `check_soil` 的原始数据

### 4.3 浇水流程测试

在 **模式选择** 页面触发「手动浇水」:

1. 选中"手动浇水" → 按下编码器确认
2. 观察流程: 先开阀门 → 等 5 秒 → 开水泵 → 逐阀切换 → 关泵 → 关阀
3. 按 **KEY3** 紧急停止, 所有继电器应立即断开

### 4.4 TCP 远程控制测试

1. 确认设备已连接 WiFi 且 OLED 上 IP 地址正常
2. 设备会自动连接 `tcp.tlink.io:8647`, 每 40 秒发心跳 `q`
3. 通过 tlink.io 平台下发指令测试:
   - 发送 `1`~`N`: 打开对应电磁阀（10 分钟后自动关闭）
   - 发送 JSON: `{"hand":1}` 触发手动浇水, `{"shut":1}` 停止

## 五、常见问题

| 问题 | 检查项 |
|------|--------|
| 烧录失败 | RS485 模块是否已断开？USB 线是否数据线（非仅充电线）？ |
| OLED 不亮 | I2C 接线 (GPIO21/22) 是否牢固？ |
| 连不上 WiFi | SSID/密码是否正确？WiFi 是否为 2.4GHz（ESP32 不支持 5G）？ |
| 传感器读数为 0 | RS485 接线是否正确？波特率是否 4800？模块是否已插回？ |
| 继电器不动作 | 测 74HC595 的 DS/STCP/SHCP (GPIO25/26/27) 信号是否正常？ |
| KEY3 不响应 | GPIO13 上拉是否正常？按下时是否为 LOW？ |
